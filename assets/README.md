# Analyst workspace background

An illustrative workspace image generated with the built-in image generation tool for this portfolio. It is not a photograph of Devaharsha's actual office, and its decorative chart shapes do not represent project results. No client or patient records appear in the asset.

Published assets:

- `assets/analyst-workspace.webp` — full-width image, encoded for the web.
- `assets/analyst-workspace-small.webp` — a smaller version for narrow screens.

The image is decorative (`alt=""`), with CSS desaturation and a separate navy overlay to match the site palette and support text contrast. The underlying image retains its original colors. Essential text and live chart values remain HTML and SVG. WebP encoding and the small-image resize are delivery optimizations; the composition is the generated original.

## Generation prompt

Use case: photorealistic-natural.
Asset type: background photograph for a professional healthcare analyst portfolio website, wide landscape, approximately 16:9.
Primary request: an elegant, distinctive analyst workspace with subtle healthcare analytics cues. A real-looking dark walnut desk, a slim unbranded laptop opened at an oblique angle, a second understated monitor farther back, an ivory analysis notebook, a pen, and two neatly laid out printed analytical pages. Screens display only soft abstract chart forms: muted grouped columns, a cohort matrix, a simple line plot. No readable text, numbers, labels, logos, patient records, or meaningful real-world data.
Composition: cinematic close, slightly overhead oblique view rather than a generic front-on office photo. The laptop occupies the center-right, the notebook and printed charts run along the bottom edge, with the left third relatively quiet and shadowed to support large white website text. Let portions of keyboard and paper enter the center and left lower foreground so the image will still be recognizable behind web overlays. Actual professional editorial photography style; tangible materials and plausible objects. Not a website screenshot, not a mockup, no inset frames.
Lighting and palette: deep forest green shadows (#153b32), warm ivory paper, gentle sage/chartreuse light from screens, a faint warm brass highlight. Natural low-key lighting with beautiful shadow detail, thoughtful and calm. Keep enough photographic texture and readable object silhouettes for use beneath a dark translucent overlay; do not make the whole image black.
Avoid: people, hands, faces, medical equipment, stethoscopes, DNA helices, neon/cyberpunk effects, floating holographic interfaces, blue corporate stock imagery, bokeh clutter, watermarks, extra keyboards, legible writing. One cohesive background photograph, edge-to-edge.
