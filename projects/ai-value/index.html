      A measurement plan for a real pilot.

      Measure comparable work.

      Use an observed manual baseline, independently reviewed outcomes, and matched task types. These generated outcomes cannot prove a model is better.

      Include the hidden work.

      Track review, rework, failed attempts, recurring fees, integration, and maintenance. Count every attempt’s tokens while keeping business-task denominators distinct.

      Validate the value.

      Decide how capacity would be used and what evidence would count as financial benefit. A positive scenario alone does not justify a rollout or staffing change.
