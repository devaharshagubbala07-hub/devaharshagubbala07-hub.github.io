01 / The finding

A starting point
for investigation.

Use the published excess readmission ratio (ERR): predicted divided by expected readmission rates for similar patients.

What the baseline comparison shows

34 of 68 Indiana hospitals with published COPD ratios (50.0%) are above 1, compared with 47.2% nationally. This small descriptive difference identifies a question to investigate. It does not establish a significant gap, a payment penalty, or avoidable readmissions.

Next: review facility volumes, source footnotes and care-transition context before selecting hospitals for deeper review.

What “above 1” means

The CMS-published predicted rate exceeds the expected rate for that hospital and condition. A ratio of 1.05 means a 5% relative difference between those modeled rates; it is not a five percentage-point patient readmission rate.

What is being compared

Each hospital has equal weight within one condition. National context includes Indiana. No ratios are pooled across conditions, and no state-level patient readmission rate is estimated.

03 / Method

The decisions
behind the dashboard.

Python validates and preserves the source. SQLite calculates cohorts and medians. The browser reads those reproducible outputs.

01 — Source integrity

Preserve the reporting grain

Validate the SHA-256 checksum, keep six-character facility IDs, and reject duplicate hospital-condition keys. One common measurement period prevents accidental period mixing.

02 — Missing information

Keep unavailable values visible

Nationally, 3,683 rows have a published ratio but unavailable discharge counts. They remain in the baseline. Each volume-filter exclusion gets an explicit reason.

03 — Verification

Reconcile each comparison

48 region-condition-volume summaries reconcile to independent Python calculations. Nine tests cover boundaries, missing values, medians, identifiers and altered source files.

Inspect the cohort rule and data model

Facility → Result ← Measure. Result has a composite primary key of facility ID and measure ID. Foreign keys protect the joins. The full source contains 18,330 rows for 3,055 hospitals and six measures.

CASE
  WHEN err IS NULL THEN 'missing_ratio'
  WHEN :minimum > 0 AND discharges IS NULL THEN 'missing_volume'
  WHEN :minimum > 0 AND discharges < :minimum THEN 'below_volume'
  ELSE 'eligible'
END

Missing-ratio status takes precedence, so the exclusion groups do not overlap. Share above 1 uses eligible hospitals only. A SQL window calculation returns the middle ratio, or the average of the two middle ratios. Empty cohorts return null rather than zero.

Limits that affect the conclusion
  • The file reports historical hospital aggregates. It cannot support patient-level prediction, a current-performance claim, an intervention effect or a time trend.
  • Condition-specific CMS ratios are risk standardized. This project does not rebuild the risk model or infer suppressed patient counts.
  • The national comparison is descriptive. CMS payment calculations use additional information, including dual-eligibility peer groups. A ratio above 1 alone does not identify a financial penalty.
  • No confidence intervals are supplied in this extract. The dashboard does not label differences statistically significant.
  • Missing ratios have several possible explanations. Source footnotes must be reviewed before treating a missing result as a quality problem.

A useful next step

Bring a small, condition-specific review list to a quality team. Confirm service availability and source footnotes, then examine internal care-transition processes and more recent results. This analysis supports that investigation; it does not claim that a hospital improved or that savings were realized.
